## Personal Genomics

### [dna-claude-analysis](https://github.com/shmlkv/dna-claude-analysis) ⭐⭐ B-

Personal genome analysis from consumer DNA tests.

- **Supported services**: 23andMe, AncestryDNA, MyHeritage, Nebula
- **17 Analysis Scripts**:
  - `health_analysis.py` — Cardiovascular, oncology, neurology, diabetes, pharmacogenomics
  - `nutrition_analysis.py` — Lactose, gluten, caffeine, vitamins metabolism
  - `carrier_status_analysis.py` — Hereditary condition carrier status
  - `longevity_analysis.py` — Longevity-associated variants
  - `immunity_analysis.py` — Immune system markers
  - `reproductive_analysis.py` — Reproductive health
  - `pain_sensitivity_analysis.py` — Pain perception genetics
  - `sleep_chronotype_analysis.py` — Sleep patterns, circadian rhythm
  - `sports_fitness_analysis.py` — Athletic performance genetics
  - + 8 more (detox, skin, vision/hearing, cognitive, psychology, ancestry, physical traits)
- **Output**: Interactive HTML dashboard ("DNA Terminal")
- **Limitations**: Hard-coded SNP lookups, no live ClinVar/gnomAD annotations
